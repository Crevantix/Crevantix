CREVANTIX FRESH WEBSITE
========================
Upload ALL files/folders exactly as they are:

index.html
style.css
script.js
assets/

The assets folder is required. Do not rename it.

For GitHub:
1. Open your Crevantix repository.
2. Add file -> Upload files.
3. Upload index.html, style.css, script.js AND the complete assets folder.
4. Commit changes.
5. Vercel will redeploy automatically.
